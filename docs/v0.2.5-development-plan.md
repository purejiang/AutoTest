## 2. 已定决策（不要在新会话里重新讨论）

1. **左侧导航只有四项**：控制台、脚本、录制、设置。
2. **顶部栏不再放页面切换**，页面切换只靠左侧导航。
3. **顶部栏最右侧保留「设置」按钮**，点击进设置页。
4. **设备下拉移到镜像卡片左侧顶部**；右侧显示分辨率。FPS 胶囊浮在镜像舞台左上角。
5. **启动 / 停止镜像、刷新**放在镜像卡片右上角；镜像工具栏只保留特效、关键帧等辅助操作。
6. **手动控制横向 tab**：视频 / 镜像 / 文本 / 应用 / 工具，一个功能一页。
7. **控制台的“操作录制”只做镜像录制（web mode）**，不做真机 / 镜像开关。
   - 真机录制统一从「录制草稿」页新建。
   - 控制台镜像录制页放一个「新建真机录制 →」文字链接，跳到录制页并打开新建弹框。
8. **真机录制不做模式开关**；录制页保留「新建真机录制」。
9. **视频录制不持久化**，只存在当前浏览器内存。
   - 必须明确提示：「刷新即丢失」「停止后立即下载」。
   - 不建视频库，不新增视频表，不上传 Blob。
10. **录制页只显示操作录制草稿**（镜像录制 / 真机录制），视频录制和设备 screenrecord 不进入这个列表。
11. **脚本页没有大标题**；数量放进 tab 按钮：
    - 脚本库 `12`
    - 运行记录 `4`
    - 数量来自接口 `total`，不是写死。
12. **运行记录合并进脚本页**，运行详情页继续保留 `/runs/:id`。
13. **脚本编辑器删除运行弹窗**；所有“运行”都跳控制台，在控制台自动控制页启动。
14. **节点排序改为拖拽**，去掉上/下移按钮；保留 `Alt+↑/↓` 键盘兜底。
15. **设置页“执行”组包含镜像配置**，工具链只放 ADB / uiautomator2 / scrcpy-server。
16. **语言本版只支持简体中文**；`English` 置灰并标注规划中。完整 i18n 另开任务，不做半汉半英。
17. **主题支持浅色 / 深色 / 跟随系统**；主题属于 UI 偏好，走 `localStorage`，不纳入后端设置保存条。
18. **真机录制实时输出优先用现有 WS**：
    - 后端已有 `/ws/recordings/{recording_id}?since_seq=`。
    - 前端新增 recording WS composable，不再只靠 4s 轮询。
    - 轮询只作为 WS 不可用时的 fallback。
19. **设备连接 / 断开能力不能丢**：删除旧设备页后，把 `adb connect` / `disconnect` 收进控制台设备下拉的底部操作或「更多」弹框；保留 `ConnectDevice` 逻辑。
20. **运行详情的现有高级控制不能删**：`RunControls` 的暂停/恢复/单步/从节点重跑/恢复前检查属于已有后端能力；视觉稿做了简化，真实页面可以收进「更多」，但不要移除。

### 后端

```

  api/runs.py                 # 运行详情/控制/报告
  api/recorder.py             # 录制 CRUD + 录制事件 WS（已存在）
  recorder/session.py         # RecordingEventBus / 事件落库

### 关键事实

- 运行事件 WS 已存在：`/ws/runs/{run_id}`，前端 `useRunEventsWs.ts` 可参考。
- 录制事件 WS 已存在：`/ws/recordings/{recording_id}?since_seq=`，但前端录制详情目前仍是 4s 轮询。
- 录制的 `mode` 是 `web` / `physical`；控制台的镜像录制固定 `web`。
- 浏览器视频录制是 `MediaRecorder` 本地 Blob，不落库、不上传。
- 设备 screenrecord 是 `artifacts/screenrecord/*.mp4`，目前不是 recording 草稿。
- 脚本 / 运行 / 录制 / 产物文件是分开存的；不要合并表，不要往 SQLite 塞视频 Blob。

## 5. 页面规格

## 5.1 控制台 `ConsolePage.vue`

整体两栏：

```
┌──────────────────────────────────────────────┬─────────────────────┐
│ 镜像卡片                                      │ 功能卡片             │
│ ┌ 设备下拉 │ 分辨率 │        启动/停止/刷新 ┐ │ 手动控制 / 自动控制  │
│ │ 特效栏                                   │ │                     │
│ │ ┌ 镜像舞台（手机画面 + FPS 左上角） ┐     │ │ 手动：视频/镜像/文本/应用/工具 │
│ │ │ 右侧动作栏：返回/桌面/最近/截图/更多 │     │ │ 自动：脚本列表/运行监控 │
│ │ └──────────────────────────────────────┘     │ │                     │
│ │ 底部状态行（可选，保留最少量信息）           │ │                     │
└──────────────────────────────────────────────┴─────────────────────┘
```

### 镜像卡片头部

- 左：设备下拉（当前设备、状态点、型号、序列号）。
- 中：分辨率（`1344 × 2992`）。
- 右：
  - 启动 / 停止镜像按钮（主按钮）。
  - 刷新按钮（重新连接或请求关键帧；建议 `session.reconnect()`）。
  - 其他低频操作收进「更多」或不在头部。
- 设备下拉底部保留「连接设备 / 刷新设备」；选中设备行可断开网络设备（保留旧 DevicesPage 的能力）。
- 不再显示重复的“镜像中 / 已连接”长文案。
- 设备切换时：
  - 停掉当前镜像或自动重启到新设备。
  - 重置录制、视频录制等依赖设备的状态。

### 镜像舞台

- 复用 `useMirrorSession` / `CanvasRenderer` / `TouchEffectOverlay`。
- FPS 胶囊：舞台左上角，深色底、白字、绿点；数据来自 `session.stats.fps`。
- 动作栏：一列，固定在舞台右侧：
  - 返回
  - 桌面
  - 最近
  - 截图
  - 更多（系统按键：菜单、音量、电源、退格等）
- 点动作栏外部 / Esc 关闭更多菜单。
- 特效：
  - 收进「特效」popover。
  - 包含点击特效、波纹、滑动特效；全开 / 全关；显示已开启数量。
  - 状态沿用 localStorage 的三个 key。
- 空态：镜像未启动时舞台显示“镜像未启动”占位，不出现“镜像中”之类文案。

### 镜像录制（手动 tab）

- 复用 `RecordingBar`，改成嵌入样式，不占整行工具条。
- 标题「镜像录制」，标签「镜像 → 脚本」。
- 输入录制名称（可选）。
- 开始 / 暂停 / 继续 / 停止。
- 停止后可“查看录制草稿”或“转脚本”。
- 固定 `mode: 'web'`，不做真机 / 镜像开关。
- 下方文字链接「新建真机录制 →」：
  - 跳 `/recorder?new=physical`；
  - 录制页读取 query 打开 `CreateRecordingDialog`。
- 录制状态轮询 / 事件计数沿用现有逻辑；如果做实时，优先复用录制 WS。

### 视频录制（手动 tab）

- 复用 `MirrorVideoRecorder`，嵌入手动页。
- 需要镜像 canvas 和特效 overlay canvas。
- 显式警告：
  - 「视频暂不持久化：只保存在当前浏览器内存，刷新或关闭页面即丢失；需要保留请停止后立即下载。」
  - 标题旁标签「刷新即丢失」。
- 不新增上传接口，不建视频库。
- 录制中离开页面 / 刷新会丢，这是预期行为。

### 文本 / 应用 / 工具

- 文本：输入文本并发送，保留全选/清空/回车等辅助。
- 应用：应用列表、启动、包名搜索；复用旧 `DeviceControlPanel` 逻辑。
- 工具：
  - 层级树（复用 `DeviceHierarchyDrawer`）
  - logcat（复用 `DeviceLogcatDrawer`）
  - 截图（复用 `ScreenshotDialog`）
  - 设备信息
  - 设备录屏 screenrecord
  - Shell
- 这些工具只作用于当前选中设备。

### 自动控制 tab

- 脚本列表：
  - 只显示标题 + 「运行」按钮。
  - 点击标题进脚本编辑器。
  - 搜索框。
  - 「变量」按钮展开变量覆盖 JSON。
  - 刷新。
- AI 操作：保留入口，按钮 disabled，标「规划中」。
- 运行：
  - 使用当前控制台设备。
  - 读取变量面板覆盖。
  - 调 `POST /api/runs`（或现有创建运行 API）。
  - 切到运行监控。
- 运行监控：
  - 状态、脚本名、耗时、进度、通过/失败。
  - 暂停 / 继续 / 停止。
  - 每节点状态：等待 / 运行中 / 通过 / 失败 / 跳过，当前节点高亮。
  - 「详情」跳 `/runs/:id`。
  - 结束后保留“返回脚本列表”。
- 运行事件使用现有 `useRunEventsWs`；不要只靠轮询。

### 页面状态

`stores/ui.ts` 增加：

```ts
consoleTab: 'manual' | 'auto'
manualTab: 'video' | 'record' | 'text' | 'app' | 'tools'
pendingRunScriptId: string | null
```

可保留 `selectedSerial`、`eventsAutoScroll`、`logcatAutoRefresh`。
删除 `mirrorRecordHint`（旧设备页提示不再使用）。

- 可选：`GET /api/runs/{id}` 增加 `script_snapshot`，用于后续从节点重跑/快照查看；本次不是硬需求。

## 5.4 录制页 `RecordingsPage.vue`

### 列表

- 标题「录制草稿」，数量来自 `total`。
- 顶部说明：
  - 只收录操作录制（镜像录制 / 真机录制）。
  - 视频录制和设备录屏不在此列表；视频刷新即丢失。
- 操作：
  - 刷新
  - 去控制台录制（跳 `/console`，手动 tab，镜像录制）
  - 新建真机录制
- 表格列：
  - 名称 / ID
  - 状态
  - 模式
  - 设备
  - 事件数
  - 开始时间
  - 关联脚本
  - 操作（详情）
- 筛选：全部模式 / 镜像 / 真机；全部状态 / 录制中 / 已暂停 / 已停止。
- 批量删除 / 单条删除保留。
- 空态：去控制台录制 / 新建真机录制。

### 新建真机录制

- 复用 `CreateRecordingDialog`（mode=`physical`）。
- 支持 `/recorder?new=physical` 自动打开。

      const dark = choice === 'dark' ||

      document.documentElement.classList.toggle('dark', dark)
    } catch (e) {}
  </script>

## 11. 已知坑 / 注意事项

1. **镜像 canvas 挂载时机**
   - `useMirrorSession` 依赖 canvas ref。
   - 如果 session 在父组件、canvas 在 `MirrorStage`，要等 canvas 挂载后再启动。
   - 给 session 增加 `setCanvas()` / `refresh()`，或在 `MirrorStage` 内持有 session 并 `defineExpose` 控制方法。

2. **视频录制依赖两个 canvas**
   - `MirrorVideoRecorder` 需要镜像 canvas + 特效 overlay canvas。
   - 从 `MirrorPanel` 拆出后，确保 `source` 是真实 canvas，不是 ref 对象。
   - 切设备 / 停止镜像时清空正在录制的视频状态。

3. **RecordingBar 的 mode**
   - 当前固定 `mode: 'web'`，这是对的。
   - 不要为了“真机”改成 physical；真机走 `CreateRecordingDialog`。

4. **运行弹窗删除后的变量/设备**
   - 变量覆盖移到控制台自动页变量面板。
   - 设备用控制台当前设备。
   - 不要静默丢变量功能。

5. **运行记录合并**
   - `RunsPage` 的批量删除、分页、状态筛选都要保留。
   - `useRuns` 当前 limit 100；tab 数量用 `total`，列表分页不要只看 items.length。

6. **拖拽排序**
   - 搜索时禁用拖拽，否则用户以为在排全量。
   - 拖拽后只改本地 steps，不自动保存。
   - 保持 `step.id` 稳定；不要按 index 生成新 id。
   - 拖拽结束后清理 drop indicator / dragging class。

7. **主题**
   - 先读 localStorage 再挂载，避免闪白。
   - Element Plus dark css-vars 必须在项目样式之前/之后顺序正确，避免主色被覆盖。
   - CodeMirror 单独处理。
   - 主题不参与后端保存条，避免“未保存 1 项”永远不消失。

8. **录制 WS**
   - 帧格式：`state` / `event` / `pong` / `error`。
   - `event.type` 是录制 kind，`payload` 是目标信息。
   - 按 `seq` 去重；断线重连带 `since_seq`。
   - 终态后停止重连；WS 失败回退轮询，不要空白。
   - 长录制事件表限制内存（最多 1000 条）。

9. **旧链接 / 设备管理**
   - `/devices` 可能被脚本页、录制页、文档、书签引用。
   - 统一重定向 `/console`，并改掉站内 `router.push('/devices')`。
   - `/runs` 重定向 `/scripts?tab=runs`。
   - 旧设备页的 `adb connect` / `disconnect`、设备刷新不要随页面一起删掉；先抽 `DeviceConnectDialog.vue` 再删页。

10. **不要复制视觉稿的演示代码**
    - 视觉稿是静态 HTML，不是 Vue 组件。
    - 复用现有 API / query / composable，不要新造一套。
